# Car Dealership Sales Analysis

Power BI sales & profitability analysis for Prestige Cars using DAX measures (public training dataset).

## Overview
Interactive Power BI report analyzing car sales, profit, and customer geography for a car dealership. Built as a data analysis portfolio project.

## Tools
- Power BI (cards, slicers, bar/column/pie/funnel charts, custom tooltip page)
- DAX
- Excel

## Key Additions
- Authored three original DAX measures: **Avg Days in Stock**, **Total Discount**, **Avg Profit Margin** — adding an inventory and discount analysis not present in the original dataset design.
- Model-level profitability finding: the **DB9** was both the best-selling and most profitable model.

## Files
- `Prestige Cars ET final.pbix` — Power BI report
- `Prestige Cars ET- Data.xlsx` — source data
